# Gramps Place Addons

Independently maintained Gramps add-ons for working with places.

## Add-ons

- **HideDuplicatePlaceNames** — combines immediately consecutive identical
  place names in event displays for configured place types.

Further place-related add-ons may be added in their own directories.

## Development and installation

This repository is the development source. It is intentionally separate from
the Gramps user plug-in directory. A release is installed into Gramps only
after it has been tested.
