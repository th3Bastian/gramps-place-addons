# CustomDetails release history

## 1.3.0 — Initial repository release

- Extends Gramps 6.0.8 Person Details with selected attributes and a reference person.
- Adds localized kinship, Kekulé ancestry numbers and d’Aboville descendant numbers.
- Uses the Gramps home person as the shared starting person, numbered 1.
- Preserves every valid ancestry and descendant path, with cycle detection and
  notices for missing data or traversal limits.
- Provides four independent display checkboxes and an attribute allowlist, with
  alphabetical sorting, case-insensitive deduplication and shared saved settings.
- Retains the original photo and life details; aligns the photo to the top with
  five-pixel vertical margins.
- Includes English and German UI catalogs and documentation.
